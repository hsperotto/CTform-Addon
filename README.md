# CTform FreeCAD Interface

The CTform FreeCAD Interface is a FreeCAD workbench for preparing and visualizing
forging simulations performed by CTform Core.

The workbench is selected as **CTform** inside FreeCAD.

> [!IMPORTANT]
> CTform Core is proprietary software and is not distributed with this addon.
> It must be installed and licensed separately.

The addon source is licensed under LGPL-3.0-or-later. CTform branding and other
protected assets are covered by `LICENSE-Assets`.

The addon is currently being prepared for the CTform Core integration. Installation
and usage instructions will be added as the connector and workbench workflows are
implemented.
